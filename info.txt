## PART 5 — TECHNICAL SEO FIXES

Audit and implement the following in the codebase:

### Core Web Vitals
- All images must use next/image with explicit width, height, and priority on above-fold images
- Add loading="lazy" on all below-fold images
- Use next/font for all fonts (zero layout shift)
- Minimize "use client" usage — keep as much as server components as possible
- Check for render-blocking scripts; move to async/defer
- Target: LCP < 2.5s, INP < 200ms, CLS < 0.1

### Canonical & Duplicate Prevention
- Add canonical tags to all pages (already set in metadata above)
